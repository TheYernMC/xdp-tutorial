** Basic03: contando con mapas BPF

Las soluciones a las tres tareas se pueden encontrar en los siguientes
ficheros:

 * El fichero [[file:../basic04-pinning-maps/common_kern_user.h][common_kern_user.h]] contiene la nueva definición de la
   estructura =datarec=.
 * El fichero [[file:../basic04-pinning-maps/xdp_prog_kern.c][xdp_prog_kern.c]] contiene la nueva definición del mapa
   =xdp_stats_map= y la función =xdp_stats_record_action= actualizada.

Ten en cuenta que, para su uso en lecciones/tareas posteriores, el código
se movió a los siguientes ficheros:
[[file:../common/xdp_stats_kern_user.h][xdp_stats_kern_user.h]] y
[[file:../common/xdp_stats_kern.h][xdp_stats_kern.h]]. Así que, para usar la
función =xdp_stats_record_action= en programas XDP posteriores, solo
incluye los siguientes ficheros de cabecera:
#+begin_example c
#include "../common/xdp_stats_kern_user.h"
#include "../common/xdp_stats_kern.h"
#+end_example
Para una aplicación de espacio de usuario, solo se necesita la primera
cabecera.
